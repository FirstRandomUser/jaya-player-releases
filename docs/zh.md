# Jaya Player — 使用说明

Jaya Player 是一款适用于 Android TV、电视盒子和智能手机的 IPTV 播放器。
本应用**不提供任何电视频道或内容**：它只播放用户自行添加的播放列表。

---

## 1. 安装

1. 下载应用：**https://github.com/FirstRandomUser/jaya-player-releases/releases/latest/download/jaya-player.apk**（始终为最新版本），或从 [Releases](https://github.com/FirstRandomUser/jaya-player-releases/releases/latest) 页面下载。
2. 在电视盒子上，使用 **Downloader** 应用或 U 盘较为方便。
3. 首次安装时 Android 会请求允许从此来源安装 — 请允许。
4. 需要 Android 6.0 或更高版本。

之后应用会**自动**下载并安装更新（见第 10 节）。

---

## 2. 首次启动与播放列表

首次启动时会打开**设置**。

1. 点击 **播放列表 → 添加**。
2. 选择类型：
   - **M3U 链接** — 服务商提供的播放列表地址；
   - **Xtream Codes** — 服务器地址、用户名和密码；
   - **文件** — 设备或 U 盘上的 `.m3u` 播放列表。
3. **EPG**（节目单）— XMLTV 地址。通常它已包含在服务商的播放列表中，此栏可留空。如果没有节目单，请向服务商索取 EPG 地址并填在这里。
4. **每 … 小时更新** — 播放列表和节目单的更新频率。
5. 点击 **保存**。加载在后台进行 — 可立即返回观看。

可以添加多个播放列表。如果更新失败（例如没有网络），应用会在下次启动时自动重试。

## 3. 遥控器操作

| 按键 | 功能 |
|---|---|
| ▲ ▼ | 上一个 / 下一个频道 |
| ◀ | 频道列表 |
| ◀ ◀（继续向左） | 分组列表 |
| ▶ | 收藏 |
| ▶ ▶（快速按两次） | 流统计信息（开/关） |
| OK | 信息栏 |
| 再按 OK | 暂停 |
| 暂停时按 OK | 继续 |
| 长按 OK | 操作菜单（音轨、字幕、画面比例、设置） |
| 数字键 | 按编号切换频道 |
| 0 | 上一个频道 |
| 返回键两次 | 退出 |

**在频道列表中：**
- ▶ — 所选频道的节目单；
- 长按 OK — 标记模式：◀ 添加/移出收藏，▶ 删除频道（已删除的可在「已删除」分组中恢复）。

**在手机上：** 点击 — 暂停并显示信息栏；上滑 — 信息栏，下滑 — 隐藏；在左半屏向右滑 — 频道列表；在右半屏向左滑 — 收藏；长按 — 设置。

---

## 4. 节目单与回看

- 节目单保存**过去 24 小时和未来 36 小时**。
- 在频道列表中按 ▶ 打开节目单。如果服务商支持，可从**回看**中观看已播出的节目。
- 回看时：**OK** — 进度条，◀ ▶ — 步进（按住加速），**返回** — 回到直播。

---

## 5. 直播暂停（时移）

**设置 → 播放 → 直播暂停并录制。**

- **关闭：** 暂停只会定格画面；继续后回到直播。
- **开启：** 暂停后从**同一时刻**继续观看。底部显示落后于直播的时间；**返回** — 回到直播。

**暂停录制存储位置：**
- **内部存储** — 在暂停时开始录制，切换频道时删除。
- **外部存储（U 盘）** — 观看频道时持续录制，因此**暂停时 ◀ ▶ 可以后退**（视空间而定）。应用会在 U 盘上创建 `Timeshift` 文件夹，最多使用 80% 的可用空间；旧录制会自动删除。

U 盘：FAT32 或 exFAT（设备支持时可用 NTFS）。
不支持 DASH 流、加密流以及带独立音轨的流 — 这些流的暂停按普通方式工作。

---

## 6. 隐藏分组（家长控制）

1. 打开分组列表（◀ ◀），选中一个分组并**长按 OK** — 进入分组选择。
2. 用 OK 标记分组，然后按**返回**。
3. 用方向键输入密码并按 OK。默认密码为 **▶ ▶ ▶ ▶**。
4. 首次隐藏后，应用会建议你设置自己的方向键密码（例如 ▲ ▲ ◀ ▶）— 请记住它。

要重新显示隐藏分组，在分组列表中**快速按三次 ◀** 并输入密码。应用最小化后分组会再次隐藏。

---

## 7. 画中画与后台（手机）

- **画中画：** 回到主屏幕时，视频在小窗口中继续播放。
- **后台音频：** 锁屏时音频继续播放；可在通知栏中控制。

---

## 8. 设置

- **屏幕：** 自动帧率、120 Hz、信息栏显示时长、列表滚动方式、**OLED 屏幕**（防烧屏：元素位移、隐藏时钟、暂停屏保、菜单变暗）。
- **时钟：** 屏幕上的位置。
- **播放：** 画中画、后台音频、音量均衡、统计信息、直播暂停、预加载相邻频道、缓冲、User-Agent。
- **主题**（设置中的独立「主题」按钮）：现成主题（经典、OLED 纯黑、海洋、暖色、玻璃）或自定义面板、选中、文字、信息栏、时钟的颜色和透明度。
- **管理：** 密码及锁定设置项（被锁定的项目会被隐藏）。

**User-Agent** 是播放器向服务商服务器「自我介绍」的方式。如果播放列表能加载但频道打不开，请试试 **VLC**。

---

## 9. 备份

**设置 → 关于 → 导出** 将播放列表、收藏、隐藏分组和设置保存到文件。**导入** 可将其恢复 — 例如在新设备上。

---

## 10. 更新

- 应用会自动检查、下载并安装更新（可在**关于**中关闭）。
- 安装前会校验签名 — 更新无法被伪造。
- 如果应用 **90 天**无法检查更新，将进入受限模式（无节目单和回看，收藏仅 5 个频道）。只需连接网络 — 一切即可恢复。

## 12. 常见问题

- **频道打不开** — 更换 User-Agent（VLC）；在其他设备上检查播放列表。
- **没有节目单** — 检查播放列表中的 EPG 地址；打开**播放列表** — 加载错误会显示在那里。
- **手机开启音量均衡后声音有杂音** — 关闭音量均衡。
- **性能较弱的盒子播放 4K 卡顿** — 选择「大」缓冲或观看高清。
