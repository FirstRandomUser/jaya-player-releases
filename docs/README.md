## ✨ Features / Возможности

- Live TV from your own M3U / Xtream Codes playlists, TV guide (EPG), archive (catch-up)
- Live pause (Timeshift) with rewind to a USB drive
- Hardware + software decoding (MPEG-2, H.264, HEVC), 4K, HDR, automatic frame rate
- Favourites, hidden groups with password, themes, OLED burn-in protection
- Picture-in-picture and background audio on smartphones
- 12 interface languages
